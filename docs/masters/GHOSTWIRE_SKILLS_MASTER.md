## Why skills are grouped

Skills are organized into chapters/groups rather than one long undifferentiated list. This keeps character creation cleaner, lets classes point to the skills they care about, and gives the master rules document a durable, readable skeleton.

| Skill chapter | Focus |
|---|---|
| Action skills | Physical action, combat-adjacent movement, infiltration, survival |
| Technical skills | Gear, hacking, repair, cybernetics, electronics, medicine |
| Knowledge skills | Lore, research, institutions, history, occult, matrix theory |
| Social skills | Negotiation, command, deception, contacts, performance, interrogation |
| Vehicle and drone skills | Piloting, pursuit, remote operation, rigging, field handling |
| Magic and supernatural skills | Ritual handling, wards, taint sensing, spirit knowledge, anomaly control |

Skills are deliberately broad enough to support a tactical game without creating tiny niche skills, while still distinct enough to support specialization through skill points and class packages.

## Languages (companion chapter)

Languages get a dedicated chapter because the setting includes megacities, corporate states, supernatural traditions, colonies, and nonhuman peoples. Language choice should matter in diplomacy, infiltration, matrix forensics, ritual research, and faction play, but shouldn't become bookkeeping-heavy unless a campaign wants that depth.

### Language rules baseline

- Every character begins with **Trade Cant** or another agreed common urban language appropriate to the campaign region.
- Characters gain additional starting languages from background, class, species, education, or special perks.
- Machine translation can assist simple communication but should impose limits on nuance, code phrases, ritual language, and deception-heavy scenes.
- Ancient, sacred, encrypted, or extradimensional languages usually require actual knowledge rather than casual machine translation.

### Working language categories

| Language group | Examples and function |
|---|---|
| Common urban tongues | Trade Cant, metro dialects, corporate pidgins, undercity slang |
| National or cultural tongues | Region-specific human languages, legacy tongues, colony dialects |
| Corporate languages | Internal corp code-speech, legal shorthand, operations dialects |
| Arcane and sacred languages | Ritual speech, saint-cant, demon names, liturgical formulae |
| Machine and matrix languages | Old code dialects, machine markup, AI symbolic exchange, resonance notation |
| Ancestral tongues | Languages tied to species, enclaves, revenant traditions, changer packs, mutant communities |
| Extradimensional tongues | Infernal speech, void cant, alien colony trade forms, off-world technical creoles |

### Language design intent

Languages should create access, secrecy, and flavor rather than constant blockage. A useful baseline: common social scenes proceed with shared tongues, while hidden archives, cult rites, corp black sites, and nonhuman enclaves become more interesting because language expertise opens special doors.
