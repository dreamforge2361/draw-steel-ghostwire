# GHOSTWIRE — Languages (framework source)

**Compiled:** 2026-09-16 · **Source:** `master_rules_baseline.md` (Book Two — The Rules)
**Authors:** Michael Frantz & Jarvis, his AI Partner.

Languages are a dedicated chapter because the setting includes megacities, corporate
states, supernatural traditions, colonies, and nonhuman peoples. Language choice should
matter in **diplomacy, infiltration, matrix forensics, ritual research, and faction
play** — but it should not become bookkeeping-heavy unless a campaign wants that depth.

## 1. Language rules baseline

- Every character begins with **Trade Cant** (or another agreed common urban language
  appropriate to the campaign region).
- Characters gain **additional starting languages** from background, class, species,
  education, or special perks.
- **Machine translation** can assist simple communication, but imposes limits on
  nuance, code phrases, ritual language, and deception-heavy scenes.
- **Ancient, sacred, encrypted, or extradimensional** languages usually require actual
  knowledge rather than casual machine translation.

## 2. Working language categories

| Language group | Examples and function |
|---|---|
| **Common urban tongues** | Trade Cant, metro dialects, corporate pidgins, undercity slang |
| **National or cultural tongues** | Region-specific human languages, legacy tongues, colony dialects |
| **Corporate languages** | Internal corp code-speech, legal shorthand, operations dialects |
| **Arcane and sacred languages** | Ritual speech, saint-cant, demon names, liturgical formulae |
| **Machine and matrix languages** | Old code dialects, machine markup, AI symbolic exchange, resonance notation |
| **Ancestral tongues** | Languages tied to species, enclaves, revenant traditions, changer packs, mutant communities |
| **Extradimensional tongues** | Infernal speech, void cant, alien colony trade forms, off-world technical creoles |

## 3. Language design intent

Languages should create **access, secrecy, and flavor** rather than constant blockage.
A useful baseline: common social scenes can proceed with shared tongues, while hidden
archives, cult rites, corp black sites, and nonhuman enclaves become more interesting
because **language expertise opens special doors**.

## 4. How Languages connect to the rest of the rules

- **Background layer (Origin & Career):** most **Origins grant a starting language**
  tied to where the hero was raised — e.g. Corp Arcology → corporate cant; Sprawl
  Undercity → street argot; Awakened Enclave → an arcane/ancestral tongue; Off-World
  Colony → an off-world trade creole; Matrix-Native → machine/code cant; Cloister of
  the Light → liturgical speech. Some **Careers** (e.g. Mage-for-Hire) grant **+1
  language**.
- **Species:** **Ancestral tongues** map to the eight species and their communities.
- **Casters (the Veil):** **Arcane and sacred languages** gate ritual research and formulae.
- **Wired / hackers & technomancers:** **Machine and matrix languages** matter for matrix forensics and deep intrusion work.
- **Skills economy:** additional languages are acquired through background, class,
  species, education, or perks (not a per-language SP tax by default).
