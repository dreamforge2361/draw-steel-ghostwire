## Paraphrased canon (Reach / Wired / Machines)

### The Reach as drone ecology
- Ossian Reach is the default vertical hive: Halo → Spires → Grid → Flats → Warrens → Sinks. Locals just say “the Reach.”
- Traffic is “second weather” in three stacked layers: choked ground, stacked air lanes, and a **constant drone swarm** filling every gap (delivery quads, surveillance eyes, ad-drones, repair-skitters, dark couriers).
- Street-level air is never empty and never quiet — drones are ambient texture, not exotic gear.

### Watched street (Ch. street-tech texture ~Lore Source §§ drones/security)
- The lit hive is saturated with cams, ceiling sensor-bugs, corp response drones, delivery/maintenance drones, and Kestrel Dynamics autonomous couriers.
- Zone gradient: **Grid** = panopticon (drawn weapon → fast response); **Flats** = pack patrols + local power (runner country); **Sinks** = near-blind (dead cams / no Signal — its own danger).
- Runner craft at street level is craft of the watched street: SIN spoof, cam hijack, knowing sweep routes. **Hacker, Wrench/Rigger (who can turn the drones), and Scout** live here.

### Wired + who commands machines
- The Wired is the unified network layer of the lit world: every door, drone, gate, and jack is a node.
- Division of labor (lore anchor): Hackers **breach** (Bandwidth); **Riggers/Wrenches command** owned machines; Technomancers **commune** via Resonance.
- Wrench is a mundane/sourceless street class — fights with skill, steel, and code, not Veil magic.

### Corps / street color touching drones
- **Kestrel Dynamics** — logistics/security conglomerate built on drones, autonomous transport, couriers; clean brand, ruthless under the gloss; network blunders into thin/waste zones.
- Flats gangs (e.g. Glass Vipers) trade **stolen drones** and grey-transit routes.
- Specialist fences include chop-shops that only move **vehicles and drones**.
- Resource/private wars escalate into air support and armor framed as the **Machines** chapter domain.

### Machines chapter intent (Wrench / Stage 1 skeleton)
- Machines = lean drones / vehicles / buildings sub-system for the Wrench (Talent reskin).
- Drones are **crewless devices** on the Wired spine: cheap, expendable, swarmable; a lost drone is a **¥ loss, not a life**.
- Control modes in Wrench card language: Autonomous / Commanded / **Jumped-In**.
- Heroic resource = **Uptime** (not nuyen). Firewall: ¥ buys hardware; Uptime runs it; chrome can improve efficiency but never generates Uptime.
- **Jump-In:** maneuver; meat body inert/exposed; biofeedback risk; temporary Integrity buffer on the machine while linked (v1 estimates in `05-wrench.md`).
- Fleet size and Uptime pool are **separate caps** in current Wrench draft; **Overheat** as an explicit backlash is an **open question** (dropped in v1 drain design — do not invent a conflicting third resource here).

### Gear spine (Cat 5E) — still starting inventory
- Eleven published drone chassis spanning recon → medic/repair/sentry → gun/anthro → apex combat, plus aquatic.
- RCC ladder (Cat 4D): Remote Box (single drone, no Jump-In) → Fleet Deck → War Table → Command Rig → Hydra Console.
- Vehicle/drone mods (Cat 5F): mounts, armor, handling, sensors, stealth coat, runflats, rigger cocoon, ammo bin — §Craft via Repair/Electronics.

### Art / setting lock (ART-STYLE)
- Cyberpunk-fantasy nocturne: rain, neon, vertical canyon, drones/VTOLs with searchlights as recurring motifs.
- Drones should feel **Reach-native**: wet chrome, LED strips, gantries, neon haze — not clean military white-box sci-fi.

## Shadowrun inspiration only (roles / sizes — no product names)

Used as design vocabulary, not copied text:
- Size bands roughly: insect/micro → palm/mini → dog-small → large-dog/motorcycle → small-car (combat heavies).
- Role families: recon/spy, sentry/patrol, gun platform, cargo/mule, medic, anthro infiltrator, aquatic sabotage, heavy assault.
- Rule of thumb often cited: if you ride inside it, treat as **vehicle**; if not, **drone**.

Ghostwire maps those ideas onto locked **Personal / Light / Vehicle (drone)** Scale bands + Domain (Air / Ground / Water).
