# Ghostwire Species ↔ Draw Steel Ancestries

**Purpose:** Keep Ghostwire species as cyberpunk reskins of Draw Steel fantasy ancestries — same creation budget and trait shape, new fiction.  
**Reference:** Draw Steel Heroes v1.01b Ancestry chapter; plus the existing **Changer = Dragon Knight** field-for-field reskin note in Downloads.

## Structural rule (Draw Steel aligned)

Draw Steel ancestries are **creation-time**:

- **1 free signature trait**
- A fixed **ancestry point budget** spent on a purchased-trait menu
- **No per-level ancestry unlock track** (growth after creation comes from class / characteristics)

Ghostwire’s older Species chapter still uses **BP options gated by level**. That is the main remaining structural drift. Target end-state: rewrite each species as a DS-style ancestry entry (signature + point menu), then drop level-gated Species Options.

The Changer/Dragon Knight reskin already demonstrates the correct pattern: **same numbers, same costs, fiction-only renames.**

## What “lines up well” means for the rewrite

For each mapped pair:

1. Keep DS **signature trait mechanic** (rename flavor only)
2. Keep DS **point costs** on purchased traits
3. Rename trait list to Ghostwire chrome/corp fiction
4. Remove Ghostwire **level-gated BP species options** (or convert leftover unique GW options into same-cost purchased traits only if they don’t break budget)
5. Class bans (Cyborg vs Veil casters) stay as **setting/chargen rules**, not ancestry-point cheats
