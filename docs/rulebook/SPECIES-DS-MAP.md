# Ghostwire Species ↔ Draw Steel Ancestries

**Purpose:** Keep Ghostwire Peoples as cyberpunk reskins of Draw Steel fantasy ancestries — same creation budget and trait shape, new fiction.  
**Reference:** Draw Steel Heroes v1.01b Ancestry chapter; **Changer = Dragon Knight** field-for-field reskin (`docs/masters/Changer-Dragon-Knight-Reskin.md`).

## Structural rule (Draw Steel aligned)

Draw Steel ancestries are **creation-time**:

- **1+ free signature trait(s)**
- A fixed **ancestry point budget** spent on a purchased-trait menu
- **No per-level ancestry unlock track** (growth after creation comes from class / characteristics)

**Status (2026-09-16):** All eight Peoples in `docs/rulebook/09-species.md` follow this rule. Level-gated BP Species Options are **retired**. Mutant Human = **Devil** chassis; Cyborg = **Time Raider** chassis (both locked).

Attribute labels in Ghostwire: **Physique, Reflex, Logic, Instinct, Persona** (Might / Agility / Reason / Intuition / Presence).  
Power Roll bands: **≤11 / 12–16 / 17+**.

## Fiction constraints retained

- Tri-register naming (scientific / corporate / slang) for all eight Peoples
- Engineered breeds: Corran, Elvani, Goliar; genetic incompatibility (breed true; no born hybrids)
- Changer lineages/forms (Raven/Rat/Wolf; Human/Hybrid/Beast)
- Revenant fire-destroys-inert (Tough But Withered)
- Mutant: optional cosmetic Corruptive Flaw; no Corruption Load economy
- Cyborg: Arcane Severance, tech-only recovery, System Crisis (setting/chargen)
