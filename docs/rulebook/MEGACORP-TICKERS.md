# Megacorp tickers (LOCKED)

**Date:** 2026-09-19  
**Status:** LOCKED  
**Module:** 0.3.10  

Each of the Ten Conglomerates has a **three-letter ticker**. Use it in writeups, Director notes, gear flavor, and table talk (e.g. “an **IRN** contract,” “**MER** Blacklight leak”).

| Ticker | Conglomerate | Domain (short) |
|---|---|---|
| **HAL** | HALO Ascendant | Orbital, energy, and life-support |
| **FER** | Ferrum Dynastic | Heavy industry, construction, hive superstructure |
| **MER** | Meridian Signal | Wired, telecom, media, information |
| **CAD** | Caduceus Vitalis | Biotech, pharma, chrome-flesh interface, medicine |
| **IRN** | Ironclad Martial | Arms, security, private military, mercenary trade |
| **ARG** | Argent Exchange | Finance, currency, scrip-and-nuyen, credit |
| **VER** | Verdant Provision | Agriculture, food, water, wasteland reclamation |
| **OBS** | Obsidian Holdings | Luxury, entertainment, vice, simsense/experience |
| **SAN** | Sanctum Assurance | Insurance, data, surveillance, private law |
| **NYX** | Nyx Cartel | Legitimized underworld — tenth seat |

## Usage
- First mention in a chapter: **Ticker** — Full Name (or Full Name (**Ticker**)).
- Thereafter: ticker alone is fine when context is clear.
- Sub-corps keep their names; parent ticker may prefix (e.g. FER Deepworks).
- Never invent an eleventh seat without Michael.

## Policy
No third-party megacorp names (B78/B83). Ghostwire Ten only.
