# NPC / token portrait art — design notes (LOCKED 2026-09-19)

**Trigger:** Michael review of B103 Corp & Security folder in Foundry after 0.3.35 ship.

## Problems observed
- Sex presentation skewed (~7♀ / 3♂ in visible corp/Ironclad portraits) — violates ~50/50 lock.
- Pink/magenta used as **dominant** lighting/wash → vaporwave / “rally neon,” not Ghostwire Core Sourcebook nocturne.

## Rules for all future humanoid NPC/token gens
1. **Sex balance:** Target ~50/50 female-to-male presentation across each batch/folder (named unique NPCs may break for fiction; the roster must still read balanced).
2. **Palette:** Near-black, charcoal, wet asphalt, deep navy/steel; accents = **cyan, amber/orange work-lamps, gold Signal**. Pink/magenta only as **thin secondary accents** (LED strip, small icon) — never the main rim light or full-frame wash.
3. **Look:** Cinematic cyberpunk-fantasy grit; tactical/street gear; high contrast shadows. Match `docs/rulebook/ART-STYLE.md` and Core Sourcebook plates — not candy cyberpunk.
4. **QA before ship:** Count ♀/♂ in the batch; reject if pink is the primary light in more than ~20% of frames.
