# Draw Steel alignment brief

**Locked 2026-09-16.** Earlier Ghostwire drafts invented a separate **tier** ladder (T5 street → T1 apex) and sometimes inverted Power Roll “Outcome Tiers.” That was a mistake relative to Draw Steel.

## Use instead

| Concept | Draw Steel / Ghostwire rulebook |
|---|---|
| Character progression | Levels **1–10** |
| Bands | **Echelon** (1–4) |
| Power Roll results | DS print order: **low / middle / high** = ≤11 / 12–16 / 17+ (do not invert) |
| Heroic ability costs | **Cost bands** / N-cost abilities (Adrenaline / Advantage / Influence / etc. costs 1–5 / 7 / 9 / 11) — not character tiers |
| Gear progression | **Availability** + echelon-appropriate lists (not gear-tiers) |
| Attributes | Physique, Reflex, Logic, Instinct, Persona (primary names; legacy Might/Agility/Reason/Intuition/Presence only as aliases) |
| Wired node grade | **Node Rating 1 (street) → 5 (alpha)** ascending — not a character tier; Integrity/Biofeedback numbers unchanged from the old T5→T1 lookup |
