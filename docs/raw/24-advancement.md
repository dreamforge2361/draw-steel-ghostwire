# Advancement and Echelons

## Levels and echelons

Runners advance from **Level 1 to Level 10** by Draw Steel’s rules. Levels group into four **echelons**:

| Echelon | Levels |
|---|---|
| **1** | 1–3 |
| **2** | 4–6 |
| **3** | 7–9 |
| **4** | 10 |

Ghostwire has **no separate tier ladder** for heroes. Level and echelon are the only progression scales.

## What the classes gain

Every class follows the same cadence. Class chapters list the exact features, choices, and restrictions.

| Level | Common gains |
|---|---|
| **1** | Subclass; signature abilities; first heroic abilities (lowest cost bands); heroic resource; Kit (or class equivalent) |
| **2** | Perk; subclass feature |
| **3** | A **7-cost** heroic ability |
| **4** | Characteristic increase; skill; perk |
| **5** | A **9-cost** heroic ability |
| **6** | Perk; subclass feature |
| **7** | Characteristic increase; skill |
| **8** | An **11-cost** heroic ability; perk |
| **9** | Subclass feature or capstone ability |
| **10** | Characteristic increase; skill; perk; **epic resource** or capstone |

Heroic ability costs come in **bands** (1, 3, 5, 7, 9, 11 of the class’s resource). A cost band is not a tier.

## What scales with echelon

| System | How echelon applies |
|---|---|
| **Kit Stamina** | Scales by echelon, as Draw Steel’s Kits do (`08`) |
| **Armor Stamina** | Uses the wearer’s echelon (`08`) |
| **Gear grade** | Echelon 1–4 plus Availability sets price and mod slots (`08`) |
| **Invent a Mod** | A new mod’s power can’t exceed the inventor’s echelon (`10`) |
| **Class resources** | Some caps and bonuses scale by echelon; see each class |

## What doesn’t scale with level

- **Body Integrity** starts at 20 and never grows by leveling (`09`).
- **¥** comes from runs, not levels (`08`).
- **Ancestry traits** are bought once at creation (`05`).
- **Node Rating** (1–5) is a Wired defense grade, not a level or echelon (`21`).

## Converting older Ghostwire material

Earlier Ghostwire drafts used a descending tier ladder (T5 weakest → T1 strongest). Read it this way:

| Old tier (hero or foe) | Level |
|---|---|
| T5 | 1 |
| T4 | 3 |
| T3 | 5 |
| T2 | 7 |
| T1 | 9 |

| Old gear tier | Echelon | Availability |
|---|---|---|
| T5 | 1 | Street |
| T4 | 1 | Professional |
| T3 | 2 | Restricted |
| T2 | 3 | Military |
| T1 | 4 | Prototype |

| Old node tier | Node Rating |
|---|---|
| T5 | 1 |
| T4 | 2 |
| T3 | 3 |
| T2 | 4 |
| T1 | 5 |

Older material that numbered Power Roll results “Tier 1 / 2 / 3” from best to worst is inverted: always use low / middle / high (`03`).
