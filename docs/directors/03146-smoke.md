# 0.3.146 — Foundry checklist

**One behaviour, one window.** A vehicle added to the **Chase HUD** now seats its riders **Pilot → Systems → Turrets → Ports** instead of dropping all of them into the Ports. Nothing else in the chase changed: same phases, same band track, same rolls, same Integrity write-through, same sounds.

Worlds on 0.3.145: module update + refresh (`F5`). **No pack was rebuilt**, no Actor, Item or number changed, and no world migration runs. The Machines › Vehicles *Chase HUD* section was corrected in the pack **source** only, so the shipped journal page still prints the old "anyone already riding starts there" sentence until the next wave that rebuilds `rulebook` — behaviour is what this checklist tests.

**Prep.** One scene, GM client. A deployed **vehicle** Actor with a token on the canvas and **four hero or NPC tokens riding it** as 0.3.137 passengers (drop them onto the vehicle until the HUD's Ports used to list all four). A **second** vehicle token with **one** rider. A **third** with **none**. Open the HUD from the crashing-car button in the Token controls. Chase not started yet.

---

## 1. Four riders fill all four stations

1. **Add Vehicle** (or select the vehicle token → **Add Selected**) for the four-rider vehicle.
2. Its card lists:
   - **Pilot** — the 1st rider, one name.
   - **Systems** — the 2nd rider, one name.
   - **Turrets** — the 3rd rider.
   - **Ports** — the 4th rider.
3. No station is empty, and no name appears twice. If all four are sitting in **Ports**, the fix is not live — stop and say so.
4. Add a fifth rider to that vehicle on the canvas, remove the vehicle from the chase and add it again: the 5th name joins the **4th** in the Ports, and the Pilot / Systems / Turrets seats are unchanged.

## 2. One rider, and no riders

1. Add the **one-rider** vehicle. → It has a **Pilot** and three empty stations. Nothing sits in the Ports.
2. Add the **no-rider** vehicle. → All four stations are empty, exactly as before this wave. The card still shows its Integrity, Handling, Speed, Scale and band.
3. Both cards still take a side (Crew / Opposition) and the first vehicle added is still the **lead**.

## 3. The table can rearrange

1. On the four-rider card, use the seat selects to move the Turrets rider into the **Pilot** seat. → The seat **swaps**: the previous Pilot is out, the new one is in, and nobody is listed twice.
2. Unseat someone entirely. → The station goes empty and the HUD does not re-seat them.
3. Move a second name into **Systems**. → The single Systems seat swaps rather than stacking.
4. Pile three names into **Turrets** and three into **Ports**. → Both accept several.
5. Re-add a vehicle whose **Pilot you seated by hand**: the Director's Pilot stays put, and the riders start at **Systems**. Nobody is evicted.

## 4. Phase 1 Pilots has somebody in it

1. **Start chase** and step to **1 Pilots**.
2. Every joined vehicle with at least one rider offers its **Pilot contest** button straight away — no hand-seating first.
3. Roll one. The Director's review window still opens, still lets the tier / winner / band be changed, and **nothing moves until Confirm**.
4. Step through **2a → 2b → 2c → 3 → 4 → 5**: Systems acts in 2a/2b/2c, Turrets and Ports in 3, and the phase hints read as they did in 0.3.141.

## 5. Nothing else moved

1. **Band fiat** still beats a roll, and the ◀ ▶ buttons still step a band at a time.
2. Queue a hit, step to **4 Integrity**, apply it. → The vehicle Actor's Stamina (Integrity) changes, its token bar follows, and 0 is a wreck.
3. Pilot contests, locks, jams, gunnery, damage, wrecks and band shifts still play their sounds, and the speaker button still mutes them for you only.
4. End the chase, reload (`F5`), reopen the HUD. → The chase state on the Scene is intact, seats included.
