## A. Grenade Throw rewrite

### Placement (the part that broke last smoke)

- [ ] Throw with a grenade in the pouch: you are asked to **place a circle before any dice roll**
      — the chat log is still empty at this point
- [ ] The circle follows the cursor, and a second **blue ring** shows the 60 ft reach from your token
- [ ] The circle is **green inside** the reach and **red outside** it
- [ ] Placement does **not** snap to a targeted token — target someone, place elsewhere, it stays where you clicked
- [ ] A click **past 60 ft** is refused with a toast naming the distance, and you can click again
- [ ] **Right-click** cancels the whole throw: no roll, no card, no grenade spent
- [ ] **Esc** does the same
- [ ] After placing, the normal Draw Steel power-roll dialog appears; cancelling it leaves **no circle behind**
- [ ] After a full resolve, the circle is **gone** and tokens under where it was are selectable on the Token layer

### Size

- [ ] The circle is **15 ft** — three squares across the radius on a default 5 ft grid
- [ ] Smoke canister is also 15 ft
- [ ] Flash-Bang / EMP / Smoke sheet text all read **15 ft** and **within 60 ft**

### The save table

- [ ] Save **Low** → full damage at the thrower's tier **+ rider**
- [ ] Save **Mid** → **half** damage, rounded down, **no rider**
- [ ] Save **High** → nothing at all
- [ ] A natural 19–20 on the **save** gets no special row (it is already tier 3 → High)
- [ ] Flash-Bang: **Dazed only on Low**. Roll a Mid save with a tier-3 throw and confirm *not* Dazed
- [ ] EMP: chrome suppressed **only on Low**; **1 round** normally, **2 rounds** when the thrower read
      HIGH (tier 3 / natural 19–20)
- [ ] EMP does no Stamina damage on any row

### Card and Stamina

- [ ] Each row prints: name, **Reflex total**, **Low / Mid / High**, and what applied
- [ ] A halved number says *"(half, rounded down)"* — a 4 does not read as a bad grenade
- [ ] A Mid save that halves a 1 prints *"halved to nothing"*
- [ ] **Stamina actually drops** on Low (full) and on Mid (half) — watch the token bar, not just the card
- [ ] Smoke canister: everyone under it picks up **Cover/Conceal**, the Conceal **stays** after the circle goes

### Known change worth eyeballing

- [ ] The circle is a **Region** (Foundry 14 merged MeasuredTemplate into Region, so the 0.3.126
      MeasuredTemplate call had nothing to create into on 14.367). It should highlight normally and
      never appear in the Regions sidebar after a resolve.

- [ ] With **Automated Animations disabled**, everything above still works (there is no hard dep)
- [ ] With **Sequencer disabled**, the built-in PIXI flash runs instead — no console errors, no toast spam
- [ ] Settings → Ghostwire: **Hit effects** (world), **Hit effect volume** (client), **Use Sequencer /
      JB2A when installed** (world) all present and all effective

**Optional modules and what they buy you** — none are required:

| Module | Effect |
|---|---|
| *(none)* | Module-owned `.ogg` impact sounds + a built-in PIXI flash: tracer for guns, slash for melee, expanding ring for grenades. **This is the default and it is complete.** |
| **Sequencer** (+ a JB2A library) | Replaces the PIXI flash with video effects (`jb2a.impact.005.orange`, `jb2a.melee_generic.slash.01.orange`, `jb2a.explosion.01.orange`). Sound is unchanged. Turn off with the *Use Sequencer / JB2A* setting. |
| **JB2A** without Sequencer | No effect — Sequencer is the player. Falls back to the built-in flash. |
| **Automated Animations** | Not used, not probed, not required. It can stay installed or be removed; Ghostwire hit FX behave identically either way. |

## Notes / decisions this build made

- **The blast circle is a `Region`, not a `MeasuredTemplate`.** Foundry 14 merged MeasuredTemplate
  into Region: `MeasuredTemplate` is no longer an embedded document of `Scene` at all, and
  `Scene#templates` is a deprecated read-only view over Regions carrying `flags.core.MeasuredTemplate`.
  0.3.126's `scene.createEmbeddedDocuments("MeasuredTemplate", …)` therefore had nothing to create
  into on 14.367 — which is very likely the other half of what Michael saw in the last smoke. A
  Region with one circular shape is the v14 spelling; `REGION_CREATE` defaults to the **Player**
  role, so a player can put their own grenade down.
- **Placement is a Ghostwire PIXI overlay, not Foundry's Region drag-create.** The v14 RegionLayer
  create flow is a multi-click shape editor for a Director building a permanent zone. A grenade needs
  one click, a live preview and a range ring, so `pickBlastPoint()` draws on `canvas.controls` — the
  layer Foundry itself uses for transient canvas furniture — and tears itself down with the promise.
- **Half rounds down, and 1 halves to 0.** A Mid save against a 1-damage tier really is nothing; the
  card has its own line for it rather than printing "0 damage".
- **Hit FX degrade to *something*, not to nothing.** The brief allowed a silent no-op without
  Sequencer; shipping module-owned sounds and a PIXI flash instead means the feature is real on a
  table with no optional modules at all, which is the point of "no hard dependency".
- **Bestiary loot is a post-pass, and the four cast generators now preserve it.** Anything flagged
  `flags.draw-steel-ghostwire.loot` survives a regen (`tools/lib/keep-loot.mjs`), the same contract
  `post-patches.json` has with the pregen generator. Mama Cassavir's hand-embedded chrome is not
  loot-flagged and is never touched by the stamp.
- **The pregen default abilities come from a committed snapshot**
  (`docs/masters/pregens/default-items.json`, refreshed by `tools/ds-default-items.mjs`) rather than
  a live read of the Draw Steel system pack, so `tools/pregen-regen-smoke.mjs` still byte-compares a
  regen on a machine with no Draw Steel installed.
