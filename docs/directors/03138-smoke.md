## 1. Schema — Items, Deploy, sheet agree

1. Open catalog Items for **Scrap-Bike**, **Bulldog**, **Buzz** (drone) and **Flatbed** (heavy).
   → Each card prints a real stat line: **Integrity N · Handling H (1–4, higher is better …) · Speed band X**. No card still says "numbers come in the damage/status pass".
2. Spot-check the rubric: Scrap-Bike (Light + fast) → **Handling 4**, Warbike → **4**, Bulldog (Vehicle + slow) → **1**, Flatbed → **1**, Buzz (Personal, no band) → **3**.
3. **Deploy** Scrap-Bike and Bulldog from a hero's inventory.
   → The deployed Actor's sheet shows the **same Handling** on the Combat tab (read-only) and on Control (editable, a 1–4 number box, not free text). Integrity max matches the card (bike 20 / car 40 / heavy 80 × echelon).
4. Open a **base asset** (Door Lock, Workshop Bench). → Handling reads **—**, not the word "fixed". A bench never contests a chase.

## 3. Handling / Integrity / armor

1. Install a **Tune Kit** on a Handling-3 machine and Deploy it → Handling reads **4**. Uninstall or toggle off → back to **3**. No separate free Piloting-edge wording anywhere on the card.
2. Install a Tune Kit on a Handling-4 machine → still **4** (clamped).
3. **Lane Skirt** still only helps in the limiter lanes and tight street-deck traffic; its card says it does **not** raise Handling.
4. Armor kits: Scrap-Weld **+6** / Plate-Up **+12** / Combat Plate **+18** / Aegis **+27** **Integrity**; one kit at a time; **no DR**. The effect on the deployed Actor is named **Machine Armor (+N Integrity)**, and **Plate-Up** says on both its card and its effect that it does **not** cost Handling.
5. The machine sheet label reads **Integrity** (not "Integrity (Stamina)"), and the Deploy toast says *Integrity N*. A hero sheet still says **Stamina** — hero Body Integrity and biofeedback are untouched.

## 4. Sensors / EW / firing

1. **Sensor Pod** = edge on sensor lock (and keeps its darkvision / thermal canvas grants). **Storm Lattice** = apex: pierces smoke, dark and spoof, and shares its lock. **Ghost Coat** = bane on enemy sensor lock. The published ladder this ship is **Pod → Lattice** — there is no mid-tier sensor mod, by design.
2. Jam / spoof breaks or denies the lock for the round, and **does not drain Uptime**. Open the Wrench **Uptime** card: the "signal jamming drains 2–4 Uptime" line is **gone**, and the card says so out loud. The machine-hit (−1) and wreck (−3) drains are still there.
3. **Signal Mule** = edge defending against jam. **Spoof Cowl** = transit / ID only, never a combat jam. **Buzz / Choir-Box / Choir-King** keep their published jam bubbles.
4. Firing: at a **moving** vehicle **with** a lock = **bane**; **from** a moving vehicle **without** a lock = **double bane**.
