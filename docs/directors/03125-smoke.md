# 0.3.125 — Foundry smoke checklist (Disengage · medical kits · hotfixes · Medic Reagents)

Run in a world with the module enabled, on Foundry 14 / Draw Steel 1.1.2+.

Node smokes first — all five must be green before you open Foundry:

```
node tools/wave-03125-smoke.mjs
node tools/voidmark-smoke.mjs
node tools/pregen-regen-smoke.mjs
node tools/next-build-wave-03122-smoke.mjs
node tools/kiosk-smoke.mjs
```

**Everything below needs a live world and was not testable while Foundry was closed for the pack
rebuild.** The Node-testable half of each lock is asserted in the smokes above; these are the
table checks.

## A · Disengage

- [ ] Open the **Ghostwire Rulebook** compendium → **Combat** → page **Rounds, turns, and actions**.
      The action-budget table's *Move action* row reads **Move … or Disengage**, and a
      **Move actions — Move vs Disengage** subsection follows it.
- [ ] The subsection prints baseline **1**, the Kit bonus, and the chrome/feature riders.
- [ ] Open a hero with **Wired Reflexes** installed. Their sheet's Disengage reads **3**
      (1 baseline + 2), and **Reaction Enhancer** alone reads **2**.
- [ ] A hero wearing a Kit with a printed Disengage bonus (Gunslinger, Raider, Mantis, Monowhip,
      Chromeblade, Breacher, Streetsweeper, Rigger's Harness, Fabricator's Bench) adds that on top.
- [ ] Ask **VOIDMARK**: *"What are the disengage rules?"* It answers from the combat chapter and
      cites it. It must **not** say the rule is not on this channel.
- [ ] Ask it *"Can I Disengage and Move on the same turn?"* — the answer is no, unless something
      grants a free or extra move action.

## B · Field Surgery Kit and Slap-Doc Kit

Put both on a hero (the Gear compendium, or **Renn Solace-Ward** from Pregens, who carries both).

### Field Surgery Kit — reusable stabilize

- [ ] A **Use Field Surgery Kit** maneuver appears on the hero's abilities the moment the kit lands
      in inventory. Its card says *stabilize*, *one ally or yourself*, and *reusable*.
- [ ] Drop an ally to **0 Stamina** (they go dying/prone). **Target their token**, then use the
      card. The ally comes back to **1 Stamina**, the dying status clears, and the chat card says
      who was stabilized.
- [ ] The kit's **quantity is still 1** — it is never spent.
- [ ] Target somebody on **positive Stamina** and use it: a warning says they are not dying, and
      **no chat card posts at all**.
- [ ] Target **two** tokens and use it: it refuses and names the problem.
- [ ] With **nothing** targeted it resolves on the user (drop the user to 0 to see it).
- [ ] **The edge:** with the kit in inventory, roll a **Medicine** test (sheet → skills). The roll
      dialog shows **1 edge** the moment Medicine is selected in the skill picker, and **Medicine
      Lore** does too. Delete the kit → both edges are gone on the next roll.

### Slap-Doc Kit — two Recoveries and one condition

- [ ] A **Use Slap-Doc Kit** maneuver appears. Its card says *2 Recoveries*, *clear one physical
      condition*, *one ally or yourself*.
- [ ] Spend **3 Recoveries** off an ally, apply **Bleeding** and **Taunted** to them, target them,
      and use the card. They get **2 Recoveries** back, and the picker offers **Bleeding only** —
      Taunted is not physical.
- [ ] Pick Bleeding → it clears, and the chat card names both the Recoveries and the condition.
- [ ] With an ally on **full Recoveries and no conditions**: it still spends the kit, the card says
      so, and no picker appears. (That is the lock — an emergency button costs a canister.)
- [ ] The kit's quantity drops to 0 and **the item deletes itself**, taking its use ability with it.
- [ ] Sanity: a **Trauma Patch** at 0 quantity still sits in inventory. Only the Slap-Doc deletes.

## C · The four hotfixes

### C1 — Scout Conceal

- [ ] Open **Wren Sable-Corvin** (Pregens) and use **Conceal**. It rolls **2d10 + Reflex** and the
      card shows all three tiers.
- [ ] A **middle** result (12–16) applies **Cover/Conceal** to Wren's token.
- [ ] A **high** result (17+) applies Cover/Conceal **and Invisible**, and the token stops being
      drawn for anybody without a `seeInvisibility` optic.
- [ ] **Move Wren one square.** The Invisible drops, a toast says so, and the Cover/Conceal stays.
- [ ] A **natural 20** reads as tier 3 and vanishes her.
- [ ] A brand-new Scout rolled through chargen has Conceal, whatever the subclass.

### C2 — Raven Beast form

- [ ] Open a **Changer / Raven** hero, switch to **Beast** form. The canvas token becomes
      **0.5 × 0.5**, matching a Rat Beast and the compiled sprites.
- [ ] Switch back to **Human** or **Hybrid** — the token returns to the footprint it had before the
      first Beast swap, not a hard-coded 1 × 1.

### C3 — Kade Orrin-Vex

- [ ] Open **Kade Orrin-Vex** (Pregens). Inventory is **Security Rig** (heavy armor), **Riot
      Shield**, **Shock-Stick**, **Hand-Cannon**, plus PocketSec / stims / ammunition / fake SIN.
- [ ] **No Milspec Battledress and no Milspec Battle Rifle** — nothing above Echelon 1.
- [ ] Wearing the Security Rig, his Warframe Stamina band is live and his Body Integrity still reads
      **25 / 25** across the same seven Standard-grade implants.

### C4 — Frame Lock

- [ ] Kade's kit signature reads **Frame Lock**, not Hold the Line, and still taunts on hit.
- [ ] The **Warframe** kit item's description links to **Frame Lock**.
- [ ] An Operator who took the heroic **Hold the Line** has it under that name, at 2 Adrenaline,
      freeTriggered. Both can sit on one sheet without shadowing each other.

## D · Medic Reagents

Use **Renn Solace-Ward** (Medic / Street-Doc).

### No drip, and a ceiling

- [ ] Set Renn's Reagents to **6**. Start a combat. They stay **6** — they do **not** reset to
      Victories, and no "gain 0" card posts at the start of her turn.
- [ ] End the combat and start another. Still **6**. Reagents cross encounters.
- [ ] Type **30** into the Reagents field on an Echelon 1 Medic. It clamps to **10** (12 with
      Advanced Chem-Prep) and a toast says the kit is full.
- [ ] Same clamp when the **Reputation** feature or a `[[/gain N hr]]` link grants past the cap.
- [ ] A non-Medic hero's heroic resource is **not** clamped by any of this.

### Craft Reagents (the restock project)

- [ ] Renn's sheet has the **Craft Reagents** feature and, on the **Projects** tab, a
      **Craft Reagents — Restock Kit** crafting project at **0 / 30**.
- [ ] Spend her down to 2 Reagents, then set the project's points to **30**. The kit refills to
      **full capacity**, a chat card names the amount, and the project **resets to 0**.
- [ ] Complete it again on a full bag: the card says the kit was already full and grants 0.
- [ ] Delete the feature → the project goes with it. Re-add it → the project comes back.

### Spending

- [ ] **First Aid** at 0 Reagents still works and debits **nothing**.
- [ ] Use First Aid and fill the **spend** field with **2**: Reagents drop by 2 and the card says so.
      Enter **4**: they drop by 4.
- [ ] **Diagnose** and **Administer Dose** offer the same 2+ enhance field.
- [ ] **Combat Stims** (3) debits **3**. At 2 Reagents it **refuses**, in combat and out of it.
- [ ] **Full Kit Purge** costs 11 and lets you pour the rest of the bag in on top.
- [ ] **Established Protocols** stabilize/identify stay free at 0 Reagents.
- [ ] **Field Synthesis** costs 0.
- [ ] **Emergency Priority** still waives a cost when you decline to fill the spend field.

### Improvise! (Street-Doc)

- [ ] At **8** Reagents, using Improvise! **refuses** — the printed trigger is 3 or fewer — and no
      card posts.
- [ ] At **2**, it grants **+2** and posts a card.
- [ ] Using it again in the same combat refuses.
- [ ] End the combat and start a new one: the allowance comes back.
- [ ] At **capacity − 1**, it grants **1**, not 2.

## Notes for the wave

* The rulebook journal pages for **Combat**, **Kits** and **Medic** were patched **in place**, not
  regenerated. `tools/raw-to-journals.mjs` has drifted from the committed pack (a full run deletes
  an Overview page from all 28 chapters and drops `@UUID` links the current tool no longer emits),
  so re-syncing it properly deserves its own pass. If a page looks stale, that is the drift, not
  this wave.
* `data/voidmark-rules-index.json` had not been rebuilt since **0.3.104**. This wave rebuilds it, so
  VOIDMARK now answers from twenty chapters of RAW it previously could not see — expect better
  answers in places nobody asked about.
