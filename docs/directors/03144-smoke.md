# 0.3.144 — Foundry checklist

The **ground vehicle catalog rename** and **seventeen new 512² token plates**. Every ground chassis now prints *Catalog Name · Maker · what it is* the way the firearms have since 0.3.134, and keeps its street nickname on the maker line. No Handling, Integrity, mod slot, tag, price or echelon number moved this wave.

Worlds on 0.3.143: module update + refresh (`F5`). The `vehicles`, `summons` and `rulebook` packs were all rebuilt, so **reload the world after pull**. Machines already deployed into a world are renamed by a GM-only migration on `ready` — you do not need to Recall + Deploy, but see §6 if you want to watch it happen.

**Prep.** One scene, GM client. Have at least one hero with a ground vehicle Item already in inventory from before the update (any of the twenty-one), so §6 has something to rename.

## 6. The world migration (optional, but it is the risky half)

Renaming a compendium fixes the compendium and nothing a Director already bought.

1. Before updating, note a ground vehicle Item already sitting in a hero's inventory (say a **Getaway**).
2. Update and reload as GM. On `ready`, it should now read **Velvet Afterburn** — world Items, embedded copies on Actors, and deployed Machine Actors all get the pass.
3. **Rename one yourself first if you want the guard tested:** call a Getaway *Bessie* before the update. After the update it is **still Bessie** — the migration matches on `_dsid` and refuses to overwrite a name somebody chose.
4. It runs once per world. Re-running it from the console (`game.modules.get("draw-steel-ghostwire").api.vehicleRename.migrateVehicleNames({ force: true })`) changes nothing the second time.

## 7. What is *not* in this wave
