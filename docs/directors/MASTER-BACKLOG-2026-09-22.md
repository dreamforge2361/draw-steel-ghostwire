Folders are a compendium-side fact that vanishes when gear is dragged to a sheet, so the locked folder rule is compiled into a **57-SKU `_dsid` table** in new `scripts/weapon-skills.mjs`, and the smoke **re-derives that table from `src/packs/gear/weapons/` every run** — rule and table cannot drift, and an unmapped new SKU fails.
