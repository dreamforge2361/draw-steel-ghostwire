## Victories (dual use)

1. Award **+1 Victory** when a beat mattered (fight, node, extract, negotiation that changes the job).
2. **Live count** fuels class heroic resources (e.g. Operator Adrenaline = Victories).
3. At **full respite**: bank Victories → XP (**1:1**), reset Victories to **0**.
4. Level when XP ≥ threshold; subtract threshold; keep remainder. **No** auto-level on job-complete.

## Thresholds (Ghostwire default Director cadence)

| Band | XP per level | Suggested sessions (at ~2.5 Vic/session) |
|---|---|---|
| Levels **1→5** | **5 XP** | ~2 sessions |
| Levels **5→10** | **8 XP** | ~3 sessions |

**Dial:** 6/9 slower · 4/6 faster. Do not invent a second XP track.

## Full respite vs short stop

| | **Full respite** (default when the **job ends**) | **Short stop** (mid-job between sessions) |
|---|---|---|
| Recoveries | Yes | Yes |
| Bank Victories → XP | **Yes** | **No** |
| Reset Victories | **Yes** (to 0 after bank) | **No** |
| Pay Lifestyle | **Yes** | **No** |
| Payday (¥) | **Yes** (job complete) | **No** |
| Projects | Yes | Usually no |

Extra full respite only if fiction is real downtime (hospital, travel layover, week off).

## ¥ payday (per hero share, per completed job)

```
Payout ≈ U + G + ~25%(U + G)
```

- **U** = Lifestyle upkeep for the band the hero claims this full respite (`26`).
- **G** = gear allotment for the crew’s level band (table below).
- **~25%** = buffer (bribes, ammo, Medic restock, Trace scrub, fixer skim).

**L6+:** Directors may pay **half ¥ / half favor** (Restricted window, Writ cover, extract credit, named introduction) instead of full liquid.

### G by level (Quiet Floor default)

| Hero levels | Suggested U | **G** (gear allotment) | ≈ Hero share `1.25×(U+G)` |
|---|---|---|---|
| **1–2** | ¥400 (Low) | **¥1,600** | **¥2,500** |
| **3–5** | ¥1,200 (Middle) | **¥3,600** | **¥6,000** |
| **6–8** | ¥3,500 (High) | **¥8,500** | **¥15,000** (half favor OK) |
| **9–10** | ¥3,500 High (or ¥9,000 Elite rare) | **¥16,500** (Elite: **¥15,000**) | **¥25,000** (Elite: **¥30,000**) |

Skew up for heat / Trace Alert / milspec prize; skew down for quiet cut-outs. Payday lands at **job complete / full respite** — not on a short stop. Cross-link RAW `08` integrated payout table.
