# 0.3.131 — Foundry smoke checklist

**What this wave changed:** the hit effects Ghostwire draws on the canvas. Nothing else. No pack
JSON, no journals, no lang strings except one new setting, no rules.

**The one thing to prove:** a gun hit is **visible** with Automated Animations switched off.

---

## 0. Set the stage

1. **Module settings → Ghostwire.** Confirm four hit-effect settings are present:
   - *Hit effects* — **on**
   - *Hit effect volume* — above 0
   - *Use Sequencer / JB2A when installed* — leave as-is for now
   - ***Show hit effects to everyone*** — **new in 0.3.131**, on by default
2. **Manage Modules → turn OFF `Automated Animations`.** This is the whole point of the wave.
   Reload. (If you also want the strictest version of the test, turn off `Sequencer`, `JB2A - Jules
   and Ben's Animated Assets` and `ds-aa-bridge` too — the default path is supposed to look good
   with all four gone.)
3. Open a scene with a grid, drop **two tokens** far enough apart that a tracer has somewhere to go.
4. Console, once: `CONFIG.debug.ghostwireHitFx = true`. Every hit then logs which route it took
   (`sprites` or `vectors`, and the target count). Turn it back off when you are done.

---

## 1. PRIME — Double Tap, with AA off

1. Open an Operator (or any hero carrying **Double Tap**) with a loaded gun.
2. **Target the other token** (`T` over it, or left-click it with the token layer active).
3. Use **Double Tap**. Take the power roll.

**Expect, on the canvas:**

- [ ] A **muzzle flare** at the shooter's token.
- [ ] A **tracer** — a bright stretched streak — travelling shooter → target, about a fifth of a second.
- [ ] At the target: a **flare**, an **expanding ring** roughly two grid squares across, and
      **seven radial sparks**, holding for about half a second before fading.
- [ ] The impact sound still plays (`arrow-hit.ogg`), and the muzzle sound from B40 still plays.
- [ ] Rounds are still spent — the chat card still names the gun and the magazine still drops by 2.
- [ ] Console (with the debug flag on) logs `draw tracer/spark via sprites`.

**If it draws `via vectors` instead of `via sprites`:** that is the fallback, and it means
`assets/fx/*.png` did not load. It should still be visible (thicker strokes than 0.3.130). Note it
and check the console for a `FX texture … did not load` warning.

## 2. No target at all

1. **Clear your targets** (press `T` over the target again, or click empty canvas).
2. Use **Double Tap** again.

- [ ] The shooter's own token gets a **muzzle flash** — it is no longer completely blank.
- [ ] The sound still plays.
- [ ] No error in the console, no toast.

*(This is the case that read as "broken" in 0.3.130: no target points meant no drawing at all.)*

## 3. The rest of the gun list

Target a token and use each of these. Each should show the same tracer + impact:

- [ ] **Controlled Pair**
- [ ] **Suppressing Fire**
- [ ] **Breach and Clear**
- [ ] One **Fire &lt;weapon&gt;** ability spawned from an actual gun SKU (a Workhorse, a Chatterbox)

## 4. The other three kinds

- [ ] **Melee** — any Adjacent-band weapon strike, or a class melee `strike`. Expect a **crescent
      swing** across the target's near side, then a slash impact. `punch.ogg`.
- [ ] **Spell** — an Elementalist bolt, a Street Priest smite, a Technomancer working. Expect a
      **beam growing out of the caster** with a glowing head, then a blue/violet/orange burst
      depending on the ability's name. Check at least two flavours (e.g. **Fire Blast** → orange,
      **Dark Blast** → violet).
- [ ] **Grenade** — throw one. Expect the **big orange blast** at the landing point (no tracer: a
      grenade has no origin to throw from), ten sparks, `grenade-boom.ogg`, and the 20 ft blast
      template behaviour from 0.3.127 unchanged.
- [ ] Something that should get **nothing**: a Matrix Verb, a Commander's shout, Take Cover. No
      canvas effect, no sound from this file.

## 5. Everyone sees it

Needs a second connected client (a second browser window logged in as a player is enough).

- [ ] Player rolls **Double Tap** at a target. **The GM sees the same tracer and impact**, not just
      hears it.
- [ ] GM rolls an attack. **The player sees it.**
- [ ] Switch the player's client to a **different scene** and roll again — the player sees
      **nothing** (correct: it is not their scene) and nothing errors.
- [ ] Turn **Show hit effects to everyone** off, reload both clients, roll again: only the roller
      sees the beat. Turn it back on.

## 6. Sequencer / JB2A, if you have them

- [ ] Re-enable **Sequencer** and **JB2A**. Roll Double Tap. The JB2A bullet and impact should play
      instead — the pretty path is still preferred.
- [ ] Turn **Use Sequencer / JB2A when installed** off in Ghostwire settings. Roll again: the
      built-in sprites come back **without** disabling the modules themselves.
- [ ] No doubled impact (one flash, not two).

## 7. Teardown — the 0.3.130 mitigation, still holding

- [ ] Fire a **grenade** (the longest effect) and, while it is still animating, **switch scenes**.
      No console error, no orphaned flash on the new scene.
- [ ] Fire a shot and immediately **end the combat** (delete the encounter). Same.
- [ ] Switch scenes several times and fire a shot on each. The effect still draws every time — the
      texture cache is re-warmed on `canvasReady`, so a scene change must not leave you on the
      vector floor permanently. (Check the debug log still says `via sprites`.)
- [ ] After ten minutes of play, `canvas.app.ticker.count` should not be climbing.

## 8. Regression sweep (should be untouched)

- [ ] Ability-use sounds (B40) still fire on **use**, separately from the impact sound.
- [ ] Ammo spends, Reload, and the short/empty refusal all behave as they did in 0.3.130.
- [ ] Grenade blast templates, Mark, NPC loot panel, Medic reagents — all unchanged.
