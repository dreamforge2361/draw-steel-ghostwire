# 0.3.140 — Foundry checklist

**Special Sprite and Special Agent are in the Compile picker.** 0.3.139 shipped the purpose-built construct as its own ability card only, so a Technomancer who opened **Compile Sprite** and read the Archetype list found Data / Attack / Machine / Ward and nothing else. Special is now the **last entry** in that list, and in **Compile Agent**'s, and picking it runs the same locked flow the standalone card runs — roll, tier buys the Actions, then the purpose.

Worlds on 0.3.139: module update + refresh (`F5`). Only the **rulebook** pack was rebuilt this wave, and no document `_id` or `_dsid` changed — nothing needs re-dragging onto a sheet.

Offline pass first: `node tools/wave-03140-smoke.mjs` (plus `wave-03139`, `hacker-agents`, `b121-console-constructs`, `voidmark`, `pregen-regen`).

---

## 1. Compile Sprite → Special Sprite (the reported bug)

1. Open **Sabbat Vane** (or any Technomancer), on a scene, **not** in combat. Abilities tab → **Use Compile Sprite**.
   → The card posts, then the **Compile a Sprite** dialog opens. Read the Archetype dropdown: **Data-sprite / Attack-sprite / Machine-sprite / Ward-sprite / Special Sprite**. Special is **last**, and its row reads *N Stamina, purpose-built — roll first, then say what it is for.*
2. Pick **Special Sprite** and press **Compile Sprite**.
   → **No sprite appears yet.** Instead the **"What is this sprite for?"** dialog opens, and its first line already names the budget: *rolled **N** Action(s)*. Check that N matches the tier the **Compile Sprite card you just posted** printed — low **1**, middle **2**, high **3**. Nothing rolled a second time.
3. Type a purpose ("jam the turret until we are past it") and confirm.
   → A **Special Sprite (Minor/Intermediate/Advanced)** token drops beside the caster. Open its sheet: the description **opens** with **`Actions (2): jam the turret until we are past it`**.
4. Cancel the purpose dialog instead → **no sprite, and no Resonance spent.**
5. Out of combat, **Resonance did not move**. Start a combat and repeat → **3 Resonance** comes off, **once**, after the purpose is confirmed.
6. In combat with **fewer than 3 Resonance**, pick Special from the dropdown → refused with the Resonance warning, no sprite.
7. At the **sprite cap**, Compile Sprite refuses before the dropdown opens, as it always did.

## 2. Compile Agent → Special Agent (parity)

1. Hacker in **Overlay** or **Jacked In**, on a scene, not in combat. Abilities tab → **Use Compile Agent**.
   → The Archetype dropdown reads **Probe / Spike / Daemon / Watchdog / Special Agent**, Special last, same hint.
2. Pick **Special Agent**.
   → The card posts (this picker asks **before** the roll, as Compile Agent always has), then the **"What is this agent for?"** dialog opens with the budget the card's tier bought. Confirm a purpose → a **Special Agent** token drops with `Actions (N): …` on its description.
3. **Bandwidth is charged once.** In combat, compare the Hacker's Bandwidth before and after: **3 off, not 6**. Compile Agent's own 3 Bandwidth *is* the Special's 3.
4. **Linked** still refuses, and the Agent cap still refuses, exactly as for the other four archetypes.
5. Cancel the purpose dialog → no Agent. (The card has already posted and Compile Agent's Bandwidth has already been taken by the stock Use — that is the same as backing out of the archetype dropdown today.)

## 3. Recompile still refuses Special, and both standalone cards still work

1. Technomancer with a Special Sprite and a Data-sprite out. Use **Recompile**.
   → The **Sprite** list offers the **Data-sprite only** — the Special is not a reshape target. The **Archetype** list offers **Data / Attack / Machine / Ward** and **no Special Sprite**.
2. Let a Special Sprite drop to **0 Stamina**. Use **Recompile** again → it is **not** offered as a rebuild; only a destroyed Data / Attack / Machine / Ward sprite is.
3. Abilities tab → **Use Special Sprite** (the standalone card). It behaves exactly as it did in 0.3.139: card first, purpose dialog second, `Actions (N): …` on the token, **3 Resonance in combat / free out of it**.
4. Abilities tab → **Use Special Agent** (the standalone card). Same as 0.3.139, **3 Bandwidth in combat** taken after the purpose.
5. Level a Technomancer from 3 to 4 with a Special Sprite out → it re-compiles into the intermediate band **keeping** its `Actions (N): …` line, and **does not** open a purpose prompt during the refresh. Same for a Hacker and a Special Agent.

## 4. The sheet-button path, and the copy

1. Right-click the **Compile Sprite** row on the hero sheet (or its ⋮ control) → **Compile Sprite**. Pick **Special Sprite** from the dropdown.
   → Because no ability card was posted here, Ghostwire **rolls 2d10 + Logic to chat** first (flavour: *…compiles a Special Sprite — the tier buys its Actions*), and the purpose dialog then shows the budget that roll bought. No budget is ever handed out without dice.
2. Open the **Compile Sprite** Item sheet and press its **Compile** button → same: a posted roll, then the purpose, then the token. Repeat both on the **Compile Agent** side.
3. **Settings → Ghostwire → "Compile sprites when the card is used"**: the hint now names Special Sprite as part of the picker. Turn it **off** → using the card is a roll and nothing else again, and the sheet buttons still work.
4. Open the **Technomancer** rulebook journal → *Signature Abilities* page. The **In Foundry** box lists *Data / Attack / Machine / Ward — or **Special Sprite**, last in the list*, and the Special Sprite section ends with **Two ways in.**
5. Open the **Hacker** rulebook journal → *Agents -- Deck Daemons* page. Same two edits for **Special Agent**, including the note that the 3 Bandwidth is charged once.
