# 0.3.139 — Foundry checklist

**Special Agent / Special Sprite** (roll first, tier buys the Actions, purpose last), the **wired firefight checklist**, **Skillwires + skillsofts** (autosofts retired), and the **chassis mod-slot** mismatch.

Worlds on 0.3.138: module update + refresh (`F5`). The `classes`, `summons`, `matrix`, `chrome`, `rulebook`, `vehicles`, `pregens` and `bestiary` packs were rebuilt, so **reload the world after pull**. A Hacker or Technomancer already in a world does **not** get the new ability card by itself — re-run the level-1 advancement, or drag **Special Agent** / **Special Sprite** onto the sheet from **Ghostwire Classes**.

Offline pass first: `node tools/wave-03139-smoke.mjs` (plus `hacker-agents`, `kiosk`, `voidmark`, `pregen-regen`, `wave-03135`, `wave-03138`).

## 1. Special Agent (Hacker) — the order is the feature

1. Put a Hacker in **Overlay** or **Jacked In**, on a scene, **not** in combat. Abilities tab → **Use Special Agent**.
   → The card posts **first**. No archetype picker, no text box, nothing asked before the dice.
2. Only after the card posts does the **"What is this Agent for?"** dialog open, and its first line already names the budget: *rolled **N** Action(s)*. Check the number against the tier the card printed — low **1**, middle **2**, high **3**.
3. Type a purpose ("cut the cameras on floor 6") and confirm.
   → A **Special Agent (Minor/Intermediate/Advanced)** token drops beside the Hacker. Open its sheet: the description **opens** with **`Actions (2): cut the cameras on floor 6`**.
4. Out of combat, **Bandwidth did not move**. Now start a combat and Use it again → **3 Bandwidth** comes off, once, after you confirm the purpose (cancel the dialog instead and the Bandwidth stays).
5. With Bandwidth below 3 **in combat**, Use is refused **before** the roll — you do not lose the action.
6. Set the Hacker to **Linked** → Use refuses ("Agents need immersion"). Fill the Agent cap → Use refuses at cap (Special Agent never commands; that is Compile Agent's job).
7. A Special Agent counts on the **Compile Agent** sheet roster and in the Wired Console **Constructs** list, and **Decompile Agent** / 0 Stamina / end of encounter removes it like any other Agent.
8. Level the Hacker from 3 to 4 with a Special Agent out → it re-compiles into the intermediate band **keeping** its `Actions (N): …` line. It is not re-rolled.

## 2. Special Sprite (Technomancer) — the same order, the other resource

1. Technomancer, not in combat, on a scene. Use **Special Sprite**.
   → Card posts, **then** "What is this sprite for?" opens with the rolled budget, **then** the sprite manifests with `Actions (N): …` at the top of its description.
2. Out of combat, **Resonance did not move**. In combat it costs **3 Resonance**, taken after the purpose is confirmed.
3. A Technomancer may be **Linked** and still compile — sprites are Resonance, not software. (A Hacker may not; see 1.6.)
4. **Recompile** cannot reshape a Special Sprite — it is not in the reshape list.
5. The sprite counts against the sprite cap, shows on the **Compile Sprite** roster, and decompiles normally.

## 3. Wired firefight + skillsofts

1. Open **Hacker** and **Technomancer** rulebook journals. Each has a **Wired firefight -- round-by-round checklist** page with **0 Setup → 1 Scan → 2 Deep Scan → 3 Seize Control → 4 Compile / Special → 5 Command → 6 Cleanup / Jack Out**, and each names the other class's overlay.
2. Ask VOIDMARK, **no Clear Thread**: *"wired firefight"*, then *"how does Special Agent work?"*, then *"deep scan in combat"*. All three land on the new pages; the current question scores first.
3. **Ghostwire Matrix** sidebar: the folder reads **Skillsofts** (27 chips) and there is **no RCC Autosofts folder**. Search the compendium for "autosoft" → nothing but the chrome chapter sentence that retires the word.
4. Open **Targeting Soft**, **Repair Soft** and **Crafting Soft**. Each card says *Skillsoft: a chip for the **Skillwires** implant*, and the load rule: **short field action, out of combat only, never a §Craft Project**.
5. Open **Skillwires** (Ghostwire Chrome). The name is **Skillwires**, not "Skillwires / Encephalon". The card says it grants **no edge of its own**, prints **E1–E2 one / E3 two / E4 three**, and says the Hacker's **Encephalon / Cerebral Datastore** is a different implant.
6. On a hero **without** Skillwires, drag a **Repair Soft** on and right-click the row → **Load soft** is refused ("no Skillwires implant"). Install Skillwires, Load again → it takes, and the hero's **Repair** skill now shows an edge.
7. Add a second soft and Load it at level 1 → refused, **at cap (1 / 1)**. Unload the first, load the second → the edge moves.
8. Start a combat and try to Load or Unload → refused, **out of combat only**.
9. Two chrome sources on one skill (Cyber-Eyes + **Clearsight Soft**) still give **one** edge on Perception, not two.
10. Open any **RCC** (Remote Box, Fleet Deck, War Table, Command Rig, Hydra Console). No autosoft list; the mod-slot line says RCCs no longer take softs, and the two slot numbers on the card match.
11. Open pregen **Vira Kellis-Nade**: she carries a **Targeting Soft** and the **Skillwires** implant, at **5 of 20** Body Integrity.

## 4. Chassis mod slots agree with themselves

1. Open **Brick** (Vehicles › Ground). The header line says **Mod slots: 6** and the paragraph below says **Mod slots (6)**. Before this wave they said 6 and 4.
2. Open **Star-Chopper** → **2** and **2** (was 2 and 1).
3. Spot-check three more (**Hellkite**, **Bulldog**, **Leviathan**) — both numbers match the card header every time.
4. Open a **base asset** (Door Lock, Workshop Bench, Mesh-Web). It still claims **no** mod slots on either half — those were deliberately left alone, not "fixed" into advertising slots they never had.
