## A. Hit FX expand

- [ ] Gun Fire: visible **origin → target tracer**, then an impact flash + SFX on the target
- [ ] Controlled Pair: **gunshot** SFX (`pistol-double-tap.ogg`), not tech/drone/scan; both FX beats
- [ ] Spell (Bolt Barrage / Hurl Element / Kinetic Driver / a blast): **bolt** from the caster then a
      burst on the target; works with **no** Sequencer/AA installed
- [ ] Dark Blast sounds dark, Fire Blast sounds like fire, Kinetic Driver cracks — the flavour is
      picked off the ability name
- [ ] Melee strike: swing arc then impact; works without AA/Sequencer
- [ ] Grenade boom is **noticeably shorter** (1.25 s, down from 8.82 s) and does not run into the
      next hero's turn
- [ ] With Sequencer+JB2A enabled: the prettier path runs. With only an impact file resolvable, the
      travel beat is still Ghostwire's and there is **no doubled flash**
- [ ] A bow still gets no FX; a Matrix Verb and a Commander's shout still get none

## D. Mark

- [ ] **You!** on a Corp Enforcer: target gets a visible crosshair icon; the AE actually applies on use
- [ ] Attacks by the enforcer **and their allies** vs that mark show `+1 edge` in the roll dialog
- [ ] An attack by the marked creature's own side gets **no** edge (this is the Commander Mark bug)
- [ ] You! comes off at the start of the enforcer's next turn
- [ ] **Spot Target**: target marked with an icon; the **next ally** roll gets the edge, the spotter's
      own roll does not, and the mark is **spent** by that ally roll
- [ ] **Hard Tag / Quarry**: icon lands; the Hunter's **first** strike each round prints the rider line
      with the echelon number (+1 at E1); the second strike that round does not
- [ ] **Commander Mark**: icon + edge for the Commander and allies; marking a second creature lifts
      the first
- [ ] **Spotter Lock**: icon lands; **Rigged Fire / Focus Fire** get the edge and spend it; anything
      else gets nothing
- [ ] A player marking an enemy they do not own: the mark still lands (relayed through the GM)
- [ ] With no GM connected, the player gets the "no Director connected" toast rather than a silent failure
- [ ] The `[[/apply …]]` links in the card text still work as a manual override (select the token first)
