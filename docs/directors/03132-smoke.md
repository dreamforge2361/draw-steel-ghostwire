# 0.3.132 — Foundry smoke checklist

**What this wave changed:** seven places where a card printed a rule and the module did nothing with
it. One new script for the Elementalist's choices, one for the dismiss abilities, and edits to hit
FX, Spot Target, ammo and flanking. **No pack JSON changed**, so the packs were not rebuilt; the
three new abilities are built at runtime the way the Reload maneuver has been since 0.3.126.

**The five things to prove:** a Kinetic Driver draws; a Zephyr Companion does **not**; Spot Target
refuses an illegal target and lands on a legal one; an Operator with two guns is asked which; every
summon has a one-click way home.

Node smokes first, all green before you open Foundry:

```
node tools/wave-03132-smoke.mjs
node tools/wave-03131-smoke.mjs
node tools/f14-flanking-smoke.mjs
node tools/g3-lang-style-tokens-smoke.mjs
```

---

## 0. Set the stage

1. **Manage Modules → turn OFF `Automated Animations`** (as in 0.3.131 — the built-in beat is what
   this wave changed).
2. Console, once: `CONFIG.debug.ghostwireHitFx = true`. Every hit then logs the route it took, and
   every *refusal* logs `no kind for <ability>`, which is how you prove a suppression rather than
   guess at it. Turn it off when you are done.
3. Open a gridded scene. You want at least: one hero token, one **adjacent** enemy token, and one
   enemy token **well out of reach**.
4. Have an **Elementalist** (Stormcaller for the Zephyr), a **Technomancer**, a **Street Priest**, a
   **Cyborg** (for Kinetic Driver) and an **Operator carrying two loaded guns** to hand.

---

## 1. PRIME — Kinetic Driver draws, Zephyr Companion does not

### 1a. Kinetic Driver

1. Cyborg hero. **Target** a token across the room (`T`).
2. Use **Kinetic Driver**. Take the power roll.

- [ ] A **bolt travels origin → target** — the teal/lightning spell beat, not silence.
- [ ] The impact sound plays.
- [ ] Console logs `Kinetic Driver -> spell`, not `no kind for Kinetic Driver`.

### 1b. Zephyr Companion — the bolt that must not happen

1. Stormcaller Elementalist. **Target an enemy** (Baraak, or anyone) and leave the target set.
2. Use **Zephyr Companion**. Pick an element when asked (see §5c).

- [ ] The companion token is placed as before.
- [ ] **No bolt is drawn at the target you still had selected.** This is the regression.
- [ ] Console logs `no kind for Zephyr Companion`.
- [ ] **Your targets are still selected afterwards** — nothing clears them.

### 1c. Read the Weave — same test, utility side

1. Same hero, target still held.
2. Use **Read the Weave**.

- [ ] **No bolt.** Console logs `no kind for Read the Weave`.

### 1d. Nothing else went quiet

- [ ] A **Double Tap** (or any gun ability) still draws its tracer and spends its rounds.
- [ ] A **grenade** still draws its blast.
- [ ] **Holy Smite** (a real ranged magic strike) still draws a bolt.

## 2. Spot Target refuses, then lands

All three refusals should appear as a toast and **leave no chat card at all**.

1. Hero with **Spot Target**. **Clear all targets.** Use it.
   - [ ] Toast: *target the enemy you are calling out first*. **No card.**
2. **Target an ally** standing next to you. Use it.
   - [ ] Toast: *Spot Target calls out an enemy*. **No card.**
3. **Target the enemy across the room.** Use it.
   - [ ] Toast: *Spot Target reaches 1 square*. **No card.**
4. **Target the adjacent enemy.** Use it.
   - [ ] The **Spotted** effect icon appears on that enemy's token (it is `showIcon`).
   - [ ] A toast says the mark was placed.
   - [ ] **It lands even though Spot Target is an empty-power maneuver** — do not be surprised if no
         chat card posts; the mark is the point.
5. Have an **ally** attack that enemy.
   - [ ] The roll dialog shows **one edge** from the mark, and the mark is **spent** (icon gone).
6. Repeat 4 with the enemy **not owned by you** (a Director NPC, from a player client).
   - [ ] The mark still lands — the GM relay from 0.3.128 still carries it.

## 3. Two guns is a question

1. **Operator carrying two loaded guns** (e.g. a Workhorse and a Streetsweeper, both with rounds).
2. Use **Controlled Pair** (2 rounds).
   - [ ] A **Which gun?** dialog opens **before** the roll, listing **both** guns with their loaded
         rounds and capacity.
   - [ ] Pick the Streetsweeper → the card names the **Streetsweeper** and the **Streetsweeper's**
         magazine drops by 2. The Workhorse is untouched.
   - [ ] Cancel the dialog on a second try → **no card, no rounds spent, no resource spent.**
3. Unload one gun entirely (or drop it). Use **Controlled Pair** again.
   - [ ] **No dialog** — one gun is not a question.
4. Unload *both* so neither can pay. Use it.
   - [ ] **No dialog**, straight to the *empty* / *short* refusal, before the roll.
5. Use a **Fire &lt;gun&gt;** ability spawned from a weapon.
   - [ ] **No dialog** — that ability names its own gun.
6. **Rigged Fire** with a drone carrying **two** guns.
   - [ ] Same dialog, listing the platform's guns; the chosen platform gun pays.

## 4. Every summon has a way home

For each class, confirm the ability is **on the Abilities tab** (not just on an item sheet):

- [ ] **Technomancer** with Compile Sprite → **Decompile Sprite** is present.
- [ ] **Elementalist** with any summon or companion → **Dismiss Elemental** is present.
- [ ] **Street Priest** with Invoke the Pact → **Dismiss Spirit** is present.
- [ ] **Hacker** → **Decompile Agent** is still present and still works (unchanged).
- [ ] A hero of the right class **without** the summoning ability does **not** have the dismiss row.

Then, with **one** summon out:

- [ ] Use the dismiss ability → **no dialog**, the summon goes home, token removed.

With **two or more** out:

- [ ] Use it → a dialog lists each one by name with its Stamina, plus **All of them (n)**.
- [ ] Pick one → only that one goes.
- [ ] Use it again, pick **All** → the rest go.
- [ ] Cancelling the dialog does nothing at all.

## 5. The Elementalist chooses

### 5a. Elemental Shaping

1. Elementalist, **target an enemy**. Use **Elemental Shaping**.
   - [ ] A dialog offers **burst / slide / shift**, showing the 2 / 4 / 6 and 1 / 2 / 3 ladders.
2. Pick **burst**. If you have never set an attunement, you are asked for one first (see 5b).
   - [ ] The roll happens, and a line on the card reads e.g. *Burst — 4 Fire damage…*
   - [ ] The target's **Stamina actually drops** by that number.
   - [ ] A **spell beat** is drawn (this is the one Shaping mode that draws).
3. Use it again, pick **slide**, with a target.
   - [ ] The card line names the slide distance. **Nothing is moved for you** — that is deliberate.
4. Use it again, pick **shift**, with **no** target.
   - [ ] It is allowed (a shift needs nobody) and the card names the distance.
5. Use it with no target and pick **burst** or **slide**.
   - [ ] Refused with a toast, no card.
6. Spend Essence on a use.
   - [ ] The printed number goes up by 1 per Essence.

### 5b. Attunement

1. On a fresh Elementalist, use **Hurl Element**.
   - [ ] You are asked for an attunement **once**, offering acid / cold / corruption / fire /
         lightning / poison / sonic.
2. Pick **fire**. Take the roll.
   - [ ] The damage on the card is typed **fire** — not typeless.
3. Use **Hurl Element** again.
   - [ ] **No second prompt**; still fire.
4. **Right-click the Hurl Element row** on the Abilities tab.
   - [ ] An **Attunement** entry is there (switching is free in RAW). Switch to **cold**.
   - [ ] Hurl Element now rolls **cold**, and so do Bolt Barrage, Elemental Wall, Conflagration /
         Tempest, Elemental Convergence, Void Vortex, World Fissure, Difficult Ground and Cataclysm
         if the hero has them.
5. Check a **Pyromancer origin** ability (Solar Lance, Wildfire).
   - [ ] Still **fire**, whatever the attunement is. Origin abilities are typed by their own text.

### 5c. Companions

- [ ] **Zephyr Companion** asks **cold / lightning / sonic** on use, and the companion's strike rolls
      that type.
- [ ] **Boulder Companion** asks **acid / corruption**.
- [ ] **Ember Companion** asks **nothing** and stays fire — its card offers no choice.

## 6. Flanked is an encounter marker

1. **Out of combat**, walk two allies to opposite sides of an enemy.
   - [ ] **No Flanked icon appears.**
2. Start an encounter with all three **in the tracker**.
   - [ ] The Flanked icon **appears** on the enemy.
3. End the encounter (delete the combat).
   - [ ] The Flanked icon **comes off** — no stale markers left behind.
4. In a running encounter, put two allies either side of an enemy who is **not in the tracker**.
   - [ ] **No icon** on that bystander.
5. The rule itself, in and out of combat:
   - [ ] A melee strike against a genuinely flanked target still shows **one edge** in the roll
         dialog. This wave moved the icon, not the edge.

## 7. Regression sweep

- [ ] Reload still works and still lists drone / vehicle guns (0.3.130 C2).
- [ ] Commander Mark, Hard Tag, You! and Spotter Lock all still place from range — only Spot Target
      gained a requirement.
- [ ] Compile Sprite / Compile Agent / Summon Elemental / Invoke the Pact all still summon.
- [ ] Sprite and Veil **item-sheet** rosters and ✕ buttons still work — the new abilities are a second
      door, not a replacement.
- [ ] No console errors on world load, and the log lines for
      `dismiss abilities registered` and `Elementalist choices registered` are both present.
